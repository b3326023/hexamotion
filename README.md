# HEXAMOTION

[English](README.en.md) · [GitHub Pages 線上體驗](https://b3326023.github.io/hexamotion/)

HEXAMOTION 是可在桌面與手機瀏覽器操作的六軸 Stewart 平台模擬器。在賽道上拖曳賽車、在海面上改變浪向，旁邊的機構視窗會同步呈現六支致動器如何伸縮，以及台面如何轉向、傾斜或保持水平。[開啟線上工作室](https://hexamotion-studio.ywcheng.chatgpt.site)

## 系統摘要

- **場景控制**涵蓋飛行、賽車、海浪補償、地震、望遠鏡副鏡、太空對接、傾斜列車、動感影院、攝影防震、站姿平衡、曲面加工、振動掃頻與光纖耦合。每個場景都提供實景手勢、同步平台、量測與合成聲音。
- **物理遊樂場**可以投球、畫路徑讓平台帶球循跡、挑戰迷宮，並錄製實驗影片。**工程臺**提供六腿行程與負載量測、控制器比較、故障注入及實驗資料匯出。
- **模擬核心**以逆運動學將六自由度姿態轉為六支致動器的目標長度。Rapier 以 240 Hz 求解剛體與關節，Three.js 描繪機構與場景。致動器下座允許傾擺並約束缸體軸向扭轉。

原始碼位於 `app/` 與 `lib/`，回歸測試位於 `tests/`。[系統手冊](docs/system-manual.md) 說明各場景的物理假設與操作方式。各項第三方模型、影像與素材的來源及授權收錄在 [場景素材目錄](public/worlds/) 中。

十三種應用各有可操作的 3D 現場、直接拖曳與雙指手勢、可展開的精密儀器和程式合成立體聲。場景和六軸機構同時顯示，可直接對照輸入和平台實際反應。

手機版控制艙會依方向改排兩個視窗、量測與觸控儀器。「場景」、「儀表」及「工具」能從固定導覽開啟，操作時可長按踏板並同時轉向。進階工作臺同樣固定平台視窗，透過頁籤切換操控與量測。

## 開啟已建置的網頁

在 Windows 雙擊「啟動 HEXAMOTION.cmd」。需要 Node.js 22.13 或更新版本。這個啟動器會開啟 http://127.0.0.1:4187/。點頂欄的「遊樂場」或「工程臺」就能進入工作區，「場景控制」可接續原場景。手冊及下載可由頂欄的書本圖示開啟。要結束背景服務，可以雙擊「停止 HEXAMOTION.cmd」。

| 首頁直達網址 | 試試這個動作 |
|---|---|
| [飛行座艙](http://127.0.0.1:4187/?scene=flight) | 向右壓桿，看右機翼降低，再比較台面跟上的角度。 |
| [賽車跑道](http://127.0.0.1:4187/?scene=driving) | 向上加速，入彎後向下煞車，左右拖曳調整走線。 |
| [海浪補償](http://127.0.0.1:4187/?scene=marine) | 加大浪高，看作業船與底座搖晃，再讀補償後的台面傾角。 |
| [建築地震試驗](http://127.0.0.1:4187/?scene=seismic) | 提高震幅，對照地基和屋頂的側移，再改變震向比較試體讀值。 |

在實景拖曳可直接控制場景，拖曳同步平台可環視機構。雙點實景或按 Home 歸零。各儀器可從「精密操控」展開，支援滑鼠、觸控與鍵盤。由直達連結進入時，點選喇叭或操作儀器便可啟用聲場。其餘九項與素材來源均可直接從首頁場景庫進入。情境視窗的相機可將場景、機構與同步量測合存為 PNG。各場景下方的素材連結列出模型、背景與材質的作者及授權。

## 從原始碼執行

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Vite 的預設開發網址為 http://127.0.0.1:4186/。靜態建置會將共用應用及相容舊書籤的入口輸出至 dist/。

```sh
pnpm exec tsc --noEmit
pnpm test
pnpm build
pnpm start
```

## 物理與文件

Three.js 負責繪圖，Rapier 以固定 240 Hz 求解套筒、活塞、平台與球的接觸及關節。工程模式另提供以 FK 更新載台的即時運動學模式。十三種產業應用的手勢、模型限制和第一手來源收錄在手冊第三章。

`tests/worlds.ts` 驗證四個 3D 情境與機構的同步關係。以預設機構量得船體與台面合成傾角 RMS 分別為 3.373°、0.348°。地震測試中，試體相對行程峰值為 13.540 mm，九層建築依一階振形、以 90 倍長度比例顯示樓層側移。其餘測試條件與讀值見手冊第 26 章。

功能修改時，同步更新 docs/system-manual.md 與 docs/manual-meta.json。使用安裝了 ReportLab 並能使用繁體中文字型的 Python 3.10+ 執行 pnpm docs:build，再執行 pnpm docs:check。正式建置會核對下載檔與來源的雜湊。
